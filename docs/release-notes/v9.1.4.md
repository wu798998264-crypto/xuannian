## 本次更新

- 抖音下载站切换为 DLPanda 中文站，并修正结果按钮、站内导航和宣传内容的识别，避免把网页控件误判为视频。
- 解析后提供“视频、备用下载、音频、封面图片”四个项目，移除不适用于当前结果的“清晰度”前缀，下载按钮统一显示为“下载”。
- 优先获取真实视频源并完整保存到临时缓存，缓存完成后可直接在玄念中预览；预览失败不会影响解析结果和正式下载。
- 点击“下载”或“下载并收藏”时直接移动已经缓存的视频，不再重复请求同一文件；封面从缓存视频生成，音频仍可单独下载和收藏。
- 下载文件名优先使用用户粘贴的抖音视频文案，自动去除分享口令、链接、复制提示、平台宣传词、`#话题`、`@账号`、表情和无意义尾缀。
- 预览和下载只接受经过媒体地址及响应内容校验的文件，HTML、JSON 等错误响应不会进入下载列表。
- 媒体库顶层只保留“视频”和“音乐”，删除多余的“图片”分类；抖音封面仍保存在对应视频目录中。

更新不会修改已有剪切板、收藏、便签、灵感、附件或自定义存储路径。媒体下载网站仅在隔离的嵌入式浏览视图中打开，请只下载你拥有权利或已获授权的公开内容。
