## 本次更新

- 将 Windows 运行时应用 ID 恢复为安装包一直使用的稳定 ID，修复窗口与任务栏回退成 Electron 默认原子图标的问题。
- 保留现有白色星芒 Logo、应用图标、托盘图标和安装包身份，不修改用户数据目录或设置。
- 新增应用 ID 与打包配置一致性回归检查，防止后续版本再次出现任务栏图标错配。
