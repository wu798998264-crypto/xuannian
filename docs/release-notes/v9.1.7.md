# 玄念 v9.1.7

## 收藏备份与导入修复

- “收藏导出”只包含收藏、便签、灵感及其实际引用的附件，不包含剪切板历史和剪切板图片。
- 备份使用 `manifest.json` 和 `favorites-data.json`，附件路径采用跨设备可迁移的相对路径。
- 导出先写入 `.part` 文件，完成校验后原子改名，避免远程复制拿到 0 字节文件。
- “收藏导入”支持新版收藏 ZIP，也兼容旧版全量 ZIP；旧包中的剪切板记录和设备设置会被忽略。
- 导入后立即刷新收藏、便签和灵感；0 字节、损坏或非玄念 ZIP 会显示明确错误。
