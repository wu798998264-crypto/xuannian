# 玄念 v9.1.6

## 收藏备份与导入修复

- “收藏导出”现在只包含收藏、便签、灵感及其实际引用的附件，不再打包剪切板历史和剪切板图片缓存。
- 备份使用独立的收藏格式，附件路径改为跨设备可迁移的相对路径。
- 导出完成后先校验 `.part` 临时文件，再原子改名，避免远程复制拿到 0 字节文件。
- “收藏导入”支持新版收藏 ZIP，也兼容旧版全量 ZIP；旧包中的剪切板记录和设备设置会被忽略。
- 导入后立即刷新收藏、便签和灵感，并显示导入数量；0 字节或损坏 ZIP 会给出明确提示。
