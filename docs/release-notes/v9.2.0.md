# 玄念 9.2.0

- macOS 使用系统原生关闭、最小化和全屏按钮，移除主界面右上角重复的 Windows 样式按钮，保留窗口置顶。
- Mac 快捷窗口采用非激活浮层，在当前软件和桌面上弹出并接收搜索输入，避免唤起玄念主界面或切换到玄念所在桌面。
- Windows 与 macOS 共用同一种收藏备份，提示词、分类、备注及引用附件可互相导出导入。
- 修复 Windows 导出临时文件使用 `.zip.part` 时压缩格式不正确的问题；Mac 同时兼容旧版 Windows 生成的此类备份。
- 保留 9.1.11 的视频解析、自动预览、音视频下载与完整下载记录。

在 Windows「设置 → 收藏导出」导出备份包，传到 Mac 后，在「设置 → 收藏导入」选择该包即可；反向操作相同。导入会合并收藏，相同条目保留较新版本。此功能用于手动迁移，不提供两台设备的实时同步。

Mac 安装包使用临时签名，尚未进行 Apple Developer ID 公证，首次打开可能需要手动允许。升级沿用原应用标识与数据目录。
